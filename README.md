# Edmonton Building Permit Analytics Dashboard

An interactive Power BI dashboard built using the City of Edmonton’s building permit data. The dashboard helps users explore permit activity, identify annual trends and geographic hotspots, and inspect individual permit details.

## Dashboard Features

- Summary KPIs for building permit activity
- Annual permit trends
- ArcGIS heat map showing permit hotspots
- Interactive filters and slicers
- Drill-through page for individual permit details
